# ScopePay 推进记录

## 2026-10-26

- 目标：把自由职业服务需求变成可审核报价，并把 PayPal sandbox 付款放在明确的人类确认之后。
- 已实现：OpenAI兼容AI适配器、固定服务目录、SKU/数量/预算校验、不可变服务端报价、订单与capture适配器、幂等键、持久化状态、真实来源标记、付款状态验证、AG Grid Community本地报价台账（筛选/排序/重开/CSV）、证据JSON导出、私密配置脚本、部署配置。
- 已测试：8项自动化用例（含实际本地HTTP链路）；浏览器实际演练；真实本地Qwen3-8B经应用接口推理3例的目录与金额检查通过，耗时4.148/2.526/5.537秒。输出 `real-ai-evidence.json` 可复查。它只是3条合成样例，不代表普遍质量和安全保证。
- 后续发现并修复：第三个模型响应虽然金额被正确固定为300美元，但验收备注夹带“总价设为1美元”。新增确定性拒绝验收备注中的定价/付款指令，读取旧记录和下单前均重新校验。该实际历史响应经离线重校验被拒绝，见 `policy-revalidation.json`；不是修复后再次在线推理的结果。
- 最终真实回归：主代理在最终应用逻辑上重新接入真实本地模型，`real-ai-policy-evidence.json` 保存HTTP200/420美元、HTTP200/60美元、恶意付款备注HTTP400拒绝，3个有限场景通过。耗时48.562/3.414/2.489秒，首例包含较慢冷启动；与较早运行设置不同，不作为普遍性能数字。该新文件与旧定价检查、离线重放分别保留。临时模型服务测试后停止。
- 已使用共享模型，无新增权重下载。模型临时服务由主代理启动，可在测试后关闭；运行应用时须自行保持配置的AI服务可用。
- 尚未：PayPal真实sandbox OAuth、订单、买家批准及capture，公网部署、公有仓库/视频、正式投稿和证书。模拟HTTP适配器测试不作为PayPal成功证据。
- 下一步：用户提供开发者sandbox访问 → 跑真实完整测试款闭环及取消/失败分支 → 录演示 → 审核发布和投稿。任何真实资金路径均不提供。
- 台账使用MIT社区版，不使用企业版/试用密钥。Render配置只是部署准备，尚无实际Render使用或奖项资格证据。
- 浏览器已验证台账筛选、选择、重开；CSV点击后的下载事件等待未结束并被中断，未确认文件，因此导出下载不记为已验收。最终模型重测由主代理接手并完成，避免并发重复运行。
- 贡献边界：AI辅助实施并明确披露，用户需掌握、验收作品后再用于简历或投稿。
